🏠 Airbnb Performance Analytics Dashboard

1. Project Title / Headline

Airbnb Performance Analytics: Business Insights Dashboard

An interactive Power BI dashboard designed to analyze Airbnb listings, host performance, customer reviews, pricing patterns, and market trends across major cities.

2. Short Description / Purpose

The Airbnb Performance Dashboard is a visually interactive Power BI report developed to explore and analyze Airbnb business performance across multiple cities. It provides insights into listing growth, market share, property types, average prices, customer review behavior, seasonal trends, and host verification status.

The dashboard aims to help users understand market dynamics, evaluate customer trust, compare city-level performance, and identify business opportunities through data-driven insights.

3. Tech Stack

The dashboard was built using the following tools and technologies:

* 📊 Power BI Desktop – Main platform used for dashboard development and interactive data visualization.
* 🧹 Power Query – Used for data cleaning, transformation, and preparation.
* 🧠 DAX (Data Analysis Expressions) – Used to create calculated measures, KPIs, and analytical calculations.
* 🔗 Data Modeling – Used to organize data and establish relationships for effective analysis.
* 📈 Data Visualization – Used to present trends, comparisons, distributions, and performance indicators.
* 📁 File Format – `.pbix` for the Power BI project and `.png` for dashboard previews.

4. Data Source

The dashboard analyzes Airbnb listing and review data across multiple cities, focusing on property information, pricing, host profiles, customer feedback, and listing trends.

The data is organized to support comparisons across cities, property types, review frequencies, seasonal patterns, and host verification categories.

5. Features / Highlights

# Business Problem

Airbnb operates across diverse markets, making it important to understand how listing growth, property pricing, customer reviews, and host credibility vary by city. Without a consolidated analytical view, identifying market opportunities and customer trust patterns can be difficult.

# Goal of the Dashboard

To build an interactive analytical solution that provides a comprehensive view of Airbnb's performance, helping users identify trends, compare markets, and make informed, data-driven decisions.

# Dashboard Walkthrough

Page 1: Airbnb Growth & Performance

* KPI cards highlighting total listings, city count, host count, property types, and reviews.
* Historical analysis of listing growth across different business phases.
* Comparison of entire-room, hotel-room, shared-room, and private-room listings.
* Identification of peak growth periods and changes during the COVID-19 period.

Page 2: Market Share & City Comparison

* City-wise comparison of listing distribution and market share.
* Analysis of Superhost and non-Superhost listings.
* Average price comparisons across hotel rooms, entire places, shared rooms, and private rooms.
* City-level ratings analysis covering cleanliness, communication, location, and value.
* Identification of cities with stronger listing performance and customer ratings.

Page 3: Reviews, Seasonality & Trust

* Review frequency analysis showing how frequently customers leave reviews.
* Cumulative percentage analysis of reviewer activity.
* Monthly and seasonal trends in customer reviews across cities.
* Host verification and profile-picture analysis to understand trust-related indicators.
* Insights into customer engagement and potential differences in host credibility.

# Business Impact & Insights

* Growth Analysis:** Understand listing growth patterns and changes in market activity over time.
* Market Intelligence:** Compare city-level listing performance and identify leading markets.
* Pricing Insights:** Evaluate differences in average prices across accommodation types.
* Customer Satisfaction:** Compare ratings across cleanliness, communication, location, and value.
* Review Behavior:** Identify review frequency patterns and seasonal customer engagement.
* Trust & Credibility:** Examine host verification and profile-picture indicators.
* Data-Driven Decisions:** Support market research, competitive analysis, and strategic planning using interactive visualizations.
